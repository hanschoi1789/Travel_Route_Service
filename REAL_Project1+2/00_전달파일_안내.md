# 경로 계산에 사용할 파일

이 폴더 맨 위의 두 파일을 사용하면 됩니다. 저장된 결과를 읽는 데에는 API 키가 필요하지 않습니다.

- [final_places.csv](final_places.csv): 최종 장소·좌표·필수 여부·선정 근거
- [route_input.json](route_input.json): 체류시간·영업 구간·점심/저녁 도착 가능 구간

조회 시각: 2026-10-26T18:56:55.326746+09:00

여행 날짜: 2026-10-26

선정 장소: 경복궁, 즉석떡볶이궁, 무구옥 본점, 통의동마을마당

식당 두 곳을 점심과 저녁에 하나씩 배치해야 합니다. `meal_assignment_example`은 가능한 배치 예시이며 방문 순서가 아닙니다. 이동시간을 포함한 전체 일정의 실행 가능성은 경로 계산에서 확인해 주세요. 영업시간의 `null`은 미확인이므로 24시간 영업으로 처리하지 않습니다.

영업시간 미제공 장소: 1곳. 세부 필드와 시간 단위는 [ROUTE_INPUT.md](ROUTE_INPUT.md)에 있습니다.

이 파일은 위 조회 시각의 전달본입니다. 새로운 여행 결과를 사용하려면 앱에서 다시 검색한 뒤 `python scripts/package_handoff.py`를 실행하세요. 성공한 최신 결과로 이 두 파일과 전달용 ZIP을 갱신합니다. 재조회에는 `.streamlit/secrets.toml`의 API 키가 필요합니다.
